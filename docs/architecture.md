# Configuration → actual host source → future native integration

`config.py` validates one complete selection. `reference.run` deep-copies it before
calls, prechecks required data, compiles original C cores plus explicit HOST wrappers,
and invokes their APIs through ctypes. C sources in modules are unchanged except
documented portability transforms; host callbacks are separate from native closed
imports. No callback or host success qualifies a target address or owner.

| Module | Executed host entry | Additional native source included |
|---|---|---|
| touch | tr_completed_tail | native wrapper + real caller/result pool (target memcpy-free adaptation) |
| framing/controller | sfc_freeze/apply/restore → ASC + LVF + ordinary M10 u16 backend | exact accepted C composition, production imports/owner closed |
| WB | runtime_set, shot_begin, runtime_reset, shot_finish | native core, snapshot/capture adapter/purpose |
| ASC | b2y parse/pin/preflight and closed apply | ordered real C apply with 13 closed imports |
| film | FRAME current_800t_rgb or generalized GRKit Model.render (18 recipes) | no M10 bank/native hardware implementation |

Identity now uses the accepted dual original/reported C source. Config feeds
ri_json_locked, then one ri_freeze_locked attaches original+reported values to an
immutable capture. ri_bind_metadata and ri_run use the ORIGINAL carrier/S for actual
cm/nb/cd/mb validation, while synchronous local descriptor projections pass the frozen
committed only after its original/S checks. Later report edits/default/source failure
do not replace the captured value. Current software PTP16 is separate from old photos.
remain separate from uint32 software tokens. Actual photo source is ordinary M10
only, not M10-P. Production native caller/owner/13 imports/serializer ABI remain
unbound; recovered instruction mirrors are excluded. The external-segment double
and private-ready live only in host/identity and do not qualify a production builder.

ASC outputs hardware consumption plans, not RGB pixels. The film models operate in
their documented source domains and exclude M10 ISP/physical-camera claims. There is
no invented common image-domain pipeline or native owner state machine.

The product catalog has 22 styles. STYLE_ALIASES maps the original seven public
IDs onto accepted backend IDs; new IDs retain upstream effect identity. The
existing enabled/default selection remains the only selection model.
recipe_engine.py preserves mathematical definitions and INV601/FLAT601 initializers
in source order. The portable wrapper checks local gamma, delta identity/license
and bundled dependency hashes before evaluation.

ASC/guides includes controller → ASC + framing as real transitive C dependencies.
Its host glue calls actual sfc APIs. Synthetic GUI tables are constructed from
fields with artificial address labels used only for C record comparisons.
Native primitives/owner/ASC callbacks in host/controller/reference.c operate solely
on those ordinary host objects. Without local resources ASC stays closed; with
pinned local resources the real apply/restore sequence runs through host callbacks.
Native film still refuses at stage0, then GUIDES-only can run independently.
GUI failure after ASC success reports PARTIAL and preserves both restore duties.
These host callbacks do not qualify target imports, scheduling, loader or recovery.

`export.py` selects module directories and matching host wrappers, retains all
required headers, includes codec and tooling, filters private/generated extensions,
rewrites provenance to the selected closure and records every archive member hash.
ZIP uses sorted names, fixed epoch/perms and stored bytes for reproducibility.
No input FW/gamma/resource path or bytes enter it. Local runtime outputs belong in build/.

## Future patch provider seam

`leica_source/providers.py` defines the actual typed plan hook:
`PatchProvider.plan(frozen_config_bytes, original_img_bytes) -> Candidate`.
No provider or image assembler is currently implemented. Developers can add one in
source; there is no online permission service, approval token or JSON bypass.

Every candidate binds ordinary M10/version/exact original IMG hash. Each patch needs
an exact expected byte preimage and offset, replacement extent, instruction set,
documented caller/callee ABI (registers, stack, clobbers, return/failure/lifetime),
all native imports, and owned executable placement evidence. The current validator
checks type/version/hash, preimages/bounds, nonoverlap and import closure. Evidence
documents must then be substantively checked; nonempty strings alone do not prove
their claims. It does not modify an image or qualify installation.

A real assembler additionally needs resolved relocation/runtime helpers, primary
loader load/entry/length/trust coverage, resource/state ownership and full call stacks,
exact update admission and complete failure recovery. Same-version SD rejection is
a separate consumer behavior to resolve honestly, not a reason to alter the version.
Only after implementing these can a new command generate a real feature-bearing FW.
The preserved reference encoder is already capable of encoding data; rewriting it
does not fill native integration gaps.
